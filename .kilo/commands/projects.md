# Project Instructions

## Rules
- Focus only on the file the user explicitly names. Do not scan or modify other files unless asked.
- Do not run broad repo scans, glob searches, or dependency analysis unless the user asks for it.
- When fixing errors, look at the specific file and line numbers given by the editor. Do not trace through all project files.
- Keep output concise. Do not re-explain what the user already knows.
- Do not write temporary scripts to disk to fix issues. Use the edit and read tools directly.
